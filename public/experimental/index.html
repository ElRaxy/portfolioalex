SERENO

Saber qué agente trabaja y cuál necesita una respuesta.
Salida de Sereno · modo demoVer casoCerrar
Ver el código de Sereno ↗

Sesiones locales, en modo demo.

Saber qué agente necesita tu atención.

Un panel de terminal para seguir varias sesiones de desarrollo con IA, recuperar su contexto y distinguir cuáles trabajan, esperan una respuesta o carecen de información suficiente.

Decisiones y desarrollo
El problema
Con varios agentes abiertos, cuesta saber quién sigue trabajando y quién espera una respuesta. Un proceso activo puede estar en cualquiera de esos estados.
Mi aportación
Un panel de terminal para ver las sesiones, consultar su actividad y recuperar el contexto de cada una sin recorrer todas las ventanas.
Una decisión
Sereno busca llamadas a herramientas que aún no tienen respuesta. Así distingue un comando en curso de una sesión inactiva, aunque el archivo lleve tiempo sin actualizarse. Si faltan los datos, muestra un estado desconocido.

Python / curses / JSONL / tmux

Ver el código de RoguePatch Lab ↗

Prototipo con casos sintéticos. Los ensayos reales siguen pendientes.

Cuando un agente dice «hecho», comprobarlo.

Un prototipo para contrastar lo que afirma un agente de código con pruebas y condiciones de los archivos. Usa casos sintéticos; los ensayos reales siguen pendientes.

Decisiones y desarrollo
El problema
Un agente de código puede dar una tarea por hecha. Hay que contrastar esa afirmación con pruebas y con las condiciones que debía respetar.
Mi aportación
Un prototipo que comprueba lo declarado por el agente frente al estado de los archivos.
Una decisión
Obtener el veredicto a partir de evidencias tipadas y verificaciones deterministas. El prototipo usa casos sintéticos; los ensayos reales siguen pendientes.

Python / rfc8785 / SHA-256 / mypy
