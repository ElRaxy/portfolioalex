Strev

Preparar rutinas y seguir a cada atleta.

Una aplicación web propia para preparar rutinas, organizar clientes y seguir a cada atleta. El análisis de vídeo se procesa en segundo plano para que la interfaz siga disponible.

Marky

Seguir el mercado en directo a partir de zonas de precio marcadas a mano.

Usa el mismo motor que Smarty. Evalúa en directo las zonas que se marcan en el gráfico, avisa por Telegram o Discord y registra cada decisión. Trabaja en simulación y no envía órdenes.

Rol
Diseño y desarrollo del motor, el panel y la verificación. La estrategia se definió en colaboración.
Stack
Python 3.12 · FastAPI · React · TypeScript · klinecharts
Resultado
4.736 tests, panel de gráfico con dibujo de zonas y gestos táctiles, y datos de cTrader en simulación.

Smarty

Comprobar si una regla de trading aguanta antes de fiarse de ella.

Es el laboratorio del motor que comparte con Marky. Reproduce el mercado barra a barra con costes y deslizamiento. Separa los datos de ajuste de una regla de los de prueba y aplica controles contra el sobreajuste a cada estrategia.

Rol
Diseño y desarrollo del motor y la verificación. La estrategia se definió en colaboración.
Stack
Python 3.12 sin dependencias en el motor · FastAPI · React · TypeScript
Resultado
3.684 tests, controles SPA, PBO y DSR escritos en Python puro y validación walk-forward en 37 ventanas.
