03 · Evidencia

Un marco, dos tratamientos

Los cuatro casos usan un marco exterior 16:10. Strev puede cubrirlo. Sereno, SaveMyMoneyNow y Atalaya conservan la imagen completa sobre un matte propio.

Regla de contenido

La captura debe enseñar producto, no una maqueta genérica. El pie explica qué evidencia demuestra.

Regla de estructura

05 · Contrato

Riesgos y requisitos

El rediseño pertenece al producto solo si mantiene las rutas, el idioma, el tema y los puntos de conversión que ya funcionan.

EARS

  1. Cuando una ruta de caso cargue, el sistema mostrará back, cover, resumen, evidencia, decisiones, resultados y CTA compartido en ese orden.
  2. Cuando el viewport sea menor de 760 píxeles, el sistema convertirá las decisiones de dos columnas a una sin ocultar contenido.
  3. Cuando el tema cambie, el sistema conservará texto, scopes, captions y acciones con contraste suficiente.
  4. Si el usuario solicita movimiento reducido, el sistema no introducirá animación nueva en las rutas de caso.
  5. Cuando una página se prerenderice, el sistema mantendrá idioma, SEO, tarjeta social versión 3 y rutas localizadas del CV.

Fuera de alcance

  • No se reescribe JSX, routing ni traducciones.
  • No se cambia Contact, Footer, Header, Nav ni Portfolio.
  • No se alteran capturas de producto.
  • No se añaden librerías de motion.
  • No se crea una tarjeta por cada bloque narrativo.
